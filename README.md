# CRC_project
This repository contains the six files that were used to perform data analysis in the project "Host Remodeling of Genetically Defined Epithelial States Shapes Tumor Ecosystems and Clinical Progression in Colorectal Cancer". 

01_mouse_supplementary_figures.R: Builds the core mouse RNA-seq pipeline from raw subread/featureCounts output through TPM and VST normalization (dds_mouse), then generates every supplementary figure that includes AK_Tu (batch-confounded) and the n=1 metastatic-site samples: the all-samples UMAP, correlation heatmap, sequential and vs.-Polyps volcano plots, UpSet plot of upregulated genes, stage-averaged immune deconvolution stacked bar, GSEA heatmaps (vs. Polyps), and CMS subtype classification/barplot across all the mouse groups.


02_mouse_main_figures.R: Builds the main-text figures, restricted to the "core" (NormalColon/Polyps/AKP_Tu/AKPS_Tu) and "progenitor/organoid" (AK/AKP/AKPS/AKP_Tu/AKPS_Tu/organoids) sample sets, excluding AK_Tu and the metastatic sites. Includes group-specific UMAPs and correlation heatmaps, the unified 8-panel volcano figure, preranked GSEA heatmaps (parent-genotype and vs.-Polyps comparisons), per-sample immune cell deconvolution with Wilcoxon tests and lineage-panel-split barplots, and the 3-panel CMS progression barplots (AKP, AKPS, and core-group progression). Depends on objects built in 01_mouse_supplementary_figures.R —need to run that first.


CrossSpeciesClassifier.R: Trains a multinomial classifier on mouse gene co-expression module eigengenes (WGCNA-style, computed on VST-normalized mouse RNA-seq) to distinguish tumor progression stages, maps mouse genes to human orthologs (AnnotationHub/ensembldb + babelgene), computes matching module eigengenes on TCGA-COAD data, and applies the trained model to predict each TCGA sample's closest mouse-stage match (with a confidence threshold below which samples are labeled "None"). Outputs a pred_results-style table of TCGA sample IDs and predicted classes.

Helperfunctions_Human.R: Contains shared utility functions used across the human-data scripts (counts_to_tpm and map_and_collapse_ids).

CleanCode_ColonCancer_Human.R: The full human-data (TCGA-COAD) companion analysis to the mouse pipeline. Downloads and TPM-normalizes TCGA-COAD RNA-seq, stratifies samples by genomic subgroup (A/AK/AKP/AKPS, from APC/KRAS/TP53/SMAD4 mutation status), and runs CIBERSORT immune deconvolution, CMS molecular subtyping, a genotype/MSI/stage-annotated UMAP, a mutation co-occurrence UpSet plot, and a genome-wide sample correlation heatmap. The second half evaluates the mouse-to-human cross-species classifier's predicted transcriptomic classes against these genomic labels — comparing separation quality (UMAP, module-eigengene heatmap, confusion matrix), running DGE/GSEA and immune-cell/CMS composition analyses by predicted class (for both the immune-naive-organoid and tumor-trained classifiers), and comparing the two classifiers directly against each other. Also includes several reviewer-response analyses added during revision: DGE/GSEA and mutation-composition comparison of CMS-unclassified vs. classified tumors, and CRIS molecular subtype composition across both progression axes.

Survival_analysis_CRC_progression.R: Contains the files needed to conduct survival analysis and make the KM curves comparing the overall and progression free survival for the AK/AKP/AKPS-like classified samples and the polyps/AKP_Tu/AKPS_Tu-like classified samples. Additionally, this file makes the stacked bar plots that compare the AJCC stages across the AK/AKP/AKPS-like classified samples and the polyps/AKP_Tu/AKPS_Tu-like classified samples.
